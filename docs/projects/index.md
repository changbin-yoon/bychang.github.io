## 새 프로젝트 추가하기

1. `docs/projects/` 아래에 `프로젝트이름.md` 파일을 만듭니다.
2. `mkdocs.yml`의 `nav` → `프로젝트` 항목에 경로를 추가합니다.
3. `main` 브랜치에 push하면 자동으로 배포됩니다.
