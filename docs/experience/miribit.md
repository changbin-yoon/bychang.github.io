# 미리비트 · 빅데이터 개발본부

**책임** · 2020.04.01 ~ 현재 재직중

S사 데이터 플랫폼(DataOps / DataMesh) 인프라 구축 및 운영을 담당하고 있습니다.

## 1. 차세대 클라우드 네이티브 플랫폼 전환

*2025.01 ~ 현재 · S사 차세대 Bigdata Cluster PoC 및 운영 전환*

**핵심 역할** — 온프레미스(Hadoop) 환경에서 Kubernetes 환경으로 전환하는 인프라 패러다임 전환을 주도

- **Cloud Native 아키텍처 설계** — K8s 기반 Spark, Airflow, Trino 배포 전략 수립 및 최적화 튜닝
- **스토리지 현대화** — HDFS와 Object Storage(MinIO / S3) 간 성능 비교·분석 및 테스트 수행
- **쿼리 최적화** — Trino 기반 대규모 쿼리 성능 테스트 및 온프레미스 대비 성능 벤치마킹
- **운영 전환** — PoC 검증

수행한 개별 과제는 [프로젝트](../projects/index.md) 페이지에 정리했습니다.

## 2. 대규모 데이터 클러스터 운영 및 안정화

*2021.06 ~ 2024.12 · S사 Bigdata Cluster (T-Hadoop) 운영 및 관리*

- **규모** — 1,000대 이상 노드로 구성된 대규모 베어메탈 클러스터 안정 운영
- Hadoop Ecosystem(HDFS, YARN 등) 전반에 대한 심층 트러블슈팅 및 고가용성 유지
- Trino, Spark, Airflow 기반 빅데이터 플랫폼 운영·관리 및 최적화
- S사 메타트론 기반 클러스터 모니터링 시스템 운영 지원 (이천 / 청주 / 우시 사업장 연계)

!!! success "성과"
    대규모 트래픽 및 데이터 처리 환경에서 장애 가시성을 확보하고, 무중단 데이터 서비스 환경을 구축했습니다.

## 3. 데이터 분석 모델 파이프라인 고도화

*2021.06 ~ 2022.01 · S사 FDC(Fault Detection Classification) 모델 운영*

- **V1 (Hadoop MR 기반)** — Apache Azkaban으로 일일(Daily) 배치 작업을 스케줄링하고 안정적으로 운영·관리
- **V2 (Spark 기반)** — Apache Airflow를 도입해 기존 MR 작업을 Spark 기반 시간(Hourly) 단위 작업으로 고도화

!!! success "성과"
    데이터 처리 아키텍처를 현대화해 분석 주기를 단축하고 모델 예측 안정성 향상에 기여했습니다.
