# 커미조아 · SW개발팀

**사원** · 2017.05.01 ~ 2019.10.31

모션 제어 시스템 및 임베디드 소프트웨어 엔지니어링을 담당했습니다.

## 1. 반도체 / 디스플레이 물류 자동화 장비 제어 (Firmware)

- **SEMES OHT(Overhead Hoist Transport) Display 모듈 개발**
- Wafer Lot 변경 장비 알고리즘 및 Display 모듈 개발
- 장비 메인 제어부 및 사용자 인터페이스용 **LCD 모듈 펌웨어 설계·구현**
- 실시간 데이터 처리 및 장비 상태 모니터링 로직 최적화

## 2. 시스템 소프트웨어 및 인터페이스 최적화 (Driver & Library)

**Linux / Windows 크로스 플랫폼 드라이버 개발**

- **Linux** — 모션제어보드 전용 리눅스 커널 드라이버 및 상위 애플리케이션 라이브러리 개발
- **Windows** — Analog Input 제어보드용 Windows 드라이버 및 API 라이브러리 설계

**클라이언트 소프트웨어 지원**

- 모션제어보드 기반 클라이언트 SW 개발을 지원하며 하드웨어-소프트웨어 통합을 최적화
